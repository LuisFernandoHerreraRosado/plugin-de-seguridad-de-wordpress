== Description ==

WP Security Monitor es un plugin profesional diseñado para administradores que necesitan un control total sobre la seguridad de su sitio.

Funcionalidades:
* Escaneo de integridad de archivos.
* Monitoreo de logins fallidos.
* Registro de cambios en usuarios administradores.
* Detección de archivos PHP sospechosos.
* API REST protegida para integración externa.

== Installation ==

1. Sube la carpeta `wp-security-monitor` al directorio `/wp-content/plugins/`.
2. Activa el plugin a través del menú 'Plugins' en WordPress.
3. Ve a 'WP Security' en el menú lateral para ver el dashboard.
